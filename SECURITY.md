# Security Policy

## Reporting a Vulnerability

**Please report security vulnerabilities privately. Do not open public GitHub
issues for security reports.**

- Preferred: use [GitHub private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
  (the "Report a vulnerability" button on this repository's Security tab).
- If private vulnerability reporting is not available to you, contact the
  maintainers through the security contact listed in this repository's
  GitHub organization profile. (A dedicated security contact address will be
  published here before the repository is made public.)

Please include as much of the following as you can:

- A description of the vulnerability and its potential impact.
- Steps to reproduce, or a proof of concept.
- Affected versions or commits.

We will acknowledge your report as soon as we can, keep you informed of our
progress, and credit you in the fix announcement unless you prefer to remain
anonymous.

## Supported Versions

whalepod is in its first development phase. Only the `main` branch is
supported; there are no released versions yet.

| Version / Branch | Supported |
| ---------------- | --------- |
| `main`           | Yes       |
| anything else    | No        |

Once the project starts publishing releases, this section will list the
release lines that receive security fixes.
