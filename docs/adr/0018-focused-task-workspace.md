# ADR-0018：聚焦任务工作区

- 状态：已采纳（用户批准“聚焦工作区”方案，2026-10-18）
- 范围：替代 ADR-0010 决策 2 的常驻并排展示；其余领域与权限决定继续有效。

## 问题

讨论、执行、运行详情、约定和交付物同时铺开，使主任务和输入位置难以辨认。
采用已批准的 ChatGPT 风格工作区：窄导航、任务侧栏、单个主对话、底部输入与按需详情。

## 决定

1. 默认进入 Agent 执行。团队讨论是可明确切换的独立视图；不合并读模型、消息或输入。
   切换只改变可见性，保留各自草稿。讨论永不触发 Agent，@ 只用于成员。
2. 活跃或最近一次运行的输出成为主内容；审批直接出现在执行视图。
   状态只由服务端事实派生；运行结束、产出发布均不自动完成 Task。
3. 约定、运行输入、交接草稿、交付检查和复核按需在详情区展开。
   接受任务与下游接收确认仍在执行前可达；约定版本、候选私有、发布确认、审批权限不变。
4. 文件入口仅计算当前成员可见的交付物。内容仍走原受控接口，以文本渲染，保留失败与下载路径。
5. 桌面详情与对话并排，窄屏详情占用主内容区域；关闭和 Escape 返回触发位置。
   不用模态遮罩，不声明 aria-modal；导航、返回和关闭始终可达。

## 验证

组件判据与生产装配浏览器验收覆盖切换、草稿、引用落点、失败、候选隔离、审批、发布和窄屏。
