## 相对 alpha.4 的主要变化

### 1. ADR-0009 八切片收口（协作语义一年来最大的一次落地）

- **切片②** `run.followup` 下行帧 + 受理 ack + Node 分发（#180/#181）：执行中的追问
  不再"已受理、零痕迹"。
- **切片③** `task_comment → task_message` 实体升级（#185）；讨论流与执行流**读模型隔离**
  （ADR-0010，#194）；执行区指令可起 Run（三段式目标解析 + 双向锚定，#196）；
  同 Task 锚点消息加**库级镜像触发器**（#199，A0 硬化）。
- **切片⑤ resume 续跑全链**（#237）：Runtime 用 persisted load 接上**同一条会话**
  （同 session id、上下文命中、日志线性增长不复制），探针与 wire 两条驱动面都有判据。
- **切片⑥ 运行可观察性**（#208 系列）：任务房间两栏化（讨论｜执行）、Run Console 覆盖层、
  「这句话会在哪里跑」执行目标条、讨论里引用某次运行、任务级权限页。
- **切片⑦ Agent 可被指派**（#239）：指派即指令——Hub 自动产生 `origin='auto_assignment'`
  的指令消息并驱动，指派的人即责任人。
- **切片⑧ 审批档位可配置**（#241）：`approval_required` / `full_access` 固化进 profile
  digest；composer 胶囊让发送前就知情，`full_access` 需显式确认。
- **切片④ 指令权授权**（#198）：授权/撤销/名单的完整管理面。

### 2. 前端 UX 二十批（可用性与诚实性）

- **交互批次①–④**：死链/加载与错误态/缓存失效/错误口径的诚实化（#225）、断线横幅 +
  重连全量补拉 + session 过期跳转（#227）、ConfirmDialog 替代 `window.confirm` + toast
  通道 + `Cmd+Enter`（#229）、执行活动提示与加载骨架（#231）。
- **UX-6…UX-20**：composer 审批档位胶囊、⌘K 全局搜索（任务/项目/Agent 三类实体）、
  最近任务侧栏、运行时长、交付物文本预览 + 「对这个工件继续说」、工具轨迹内联 chip、
  运行卡阶段徽标与落点名、视觉密度审计门、运行完成通知（tab 徽标 + 可选系统通知）、
  闪屏在渲染期被消费的修复、动效底座（交互态/浮层在场/直播产出连续性/内容形态切换连续性）、
  `?` 快捷键速查与搜索空态教一次键位。
- **诚实性修复**：内部 id 不再冒充人名与标签（#162）、破折号前的排版门（#169）、
  深色对比度门不再是盲的（#214）。

## 已知限制（alpha 明示，不是漏项）

1. **Agent 真执行需要真实模型密钥**。全新安装的环境能一路走到"起 Run"，然后
   **如实失败**（`failed / MODEL_CREDENTIAL_UNAVAILABLE`）——这是设计行为，不是崩溃：
   配好 Node 本机密钥（`whalepod-node secrets`）后才是真实执行。Q9 的机检面到凭证边界
   为止；审批桥/Artifact/Reviewer/验收需要真密钥，由 Phase 2 外部 alpha 覆盖。
2. **敏感不兼容不拒绝启动**（#288）：插件清单的 `dshCompatibility`、Run 的
   `expectedProfileDigest` 目前**只记录不比对**。把本机 DSH 升到与 pack 审过的版本不一致时，
   失败形态可能是运行期怪错误而不是启动前明确拒绝。Alpha 期**锁一版，别自行升级 DSH**。
3. **能力契约未覆盖面**（#289）：单 Run 隔离、指令回执、事件流范围、cancel 竞态在 Q3
   契约门内没有独立判据；「升级失败回滚固定版」只有流程文档、无机检（#290）。
4. **测试代码类型债**（#183）：hub 25 / node 31 个存量类型错误未清；已上棘轮禁新增，
   但没有清零——别把「Q0 全绿」读成「测试代码类型正确」。
5. **多人部署需要 TLS**：会话 Cookie 在非 localhost 强制 `Secure`（#105 裁决维持现状，
   不加危险开关）；LAN 试用走内网 CA/自签 https 或 SSH 隧道，指引见 installation。
6. **门禁按风险分级**（G0/G1/G2）：普通 UI 变更不付分布式故障测试成本——这不等于 UI 无缺陷，
   只等于其缺陷不阻塞发布。
7. **单维护者 + AI 自主交付**：协议/migration 类变更走「自查记录留档 + CI 双绿」，
   **不等于第二人评审**；发布前的外部工程师审查仍在争取。
8. **命名冲突未解决**：GitHub 上存在同名不同定位的 `whyihaveyou/whalepod`；
   公开传播前解决（不阻内部/试用）。
9. **附件冻结**（#266）：暂不支持上传附件；不做 Project 级私有 ACL；深色模式（#236）暂缓。
10. **DSH 仍是 Preview 依赖**：不保证不可信插件的强隔离，不保证外部工具副作用可撤销。

**这是 alpha**：安全策略与协议仍在收口，不建议承载真实敏感数据。
