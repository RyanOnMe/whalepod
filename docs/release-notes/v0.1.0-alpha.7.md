# v0.1.0-alpha.7

> **本版是第一个带 GitHub Release 的版本**（alpha.1–alpha.6 只有 git tag 与
> `docs/release-notes/` 记录，从未建 Release 条目）。目标读者是**愿意部署 Compose、
> 跑真实双人闭环、并接受 alpha 风险**的外部团队。安装看 [docs/installation.md](../installation.md)；
> 限制声明在本文件末尾，**请连它一起读**。

## 为什么不是 alpha.5 / alpha.6

前两个 tag 都打过、发布工作流也都跑了，但**证据没全绿**——在红证据的树上直接建 Release 是错的。
每一轮的红都查到了根因并修掉，最后按版本序列落到 alpha.7（alpha.5/alpha.6 作为历史 tag 保留）。
这条"红就查、查完再切"的路径本身就是本版最重要的一份记录：

1. **alpha.5 那轮 · Q5 拦下一条真缺陷**：composer 输入框的 placeholder 只声明了 `color`、
   没声明 `::placeholder`，走浏览器默认色 → 4.06:1（AA 要求 4.5:1）。已在全局层修
   （`input/textarea::placeholder` 取 `label-secondary`），并补了 **Q0 快判据**——此前这类缺陷
   只有发布级 Q5 看得见，PR 期全绿是空的。
2. **alpha.5 那轮 · Q5 还暴露了门自己的缺陷**：对比度扫描器沿祖先链累乘 `opacity`，UX 动效批次
   （骨架交叉淡入/列表入场）让取样落在淡入中途，同一批文字被算成 3.03–4.46:1（稳态 5.8:1）。
   已按 poll-until 纪律加「等一次性动画收口」的有界等待（常驻动画如流式光标不阻塞，等不到留痕）。
3. **alpha.5 那轮 · Q8 判据环境问题**：runner 从 2 vCPU 升到 4 vCPU 后名义规格达 04 §8，
   闸把共享 CPU 的 runner 当判据环境，一次 ingest p95=116.4ms 判成权威 FAIL。对照：
   判据环境 14.9ms / 空闲 M4 本机 24.8ms / runner 116.4ms，而节拍压住的传播三者几乎一样。
   已把这类 runner 显式标为**非判据环境**（`sharedCi`，#298）。**本版因此不声称性能达标**
   ——见下方限制声明第 6 条。alpha.6 那轮同一 runner 规格量得 **ingest 9.1ms**
   （判定 PASS-CONSERVATIVE）：同规格两次相差 **12.8 倍**，是该指标在共享 runner 上不可判的硬证据。
4. **alpha.6 那轮 · Q5 第 15 轮红的是一条测试缺陷**：p1-140 用 `getByText('协作观察用例')` 断言
   任务标题，而 UX-10 起侧栏「最近任务」也渲染任务标题且**异步到货**——侧栏到货前只匹配 h1（过）、
   到货后匹配两个（strict mode violation，红）。已钉到 `getByRole('heading')` 并逐条核过其余
   e2e 同类断言。注意这是**20 连跑才踩得到**的碰撞（上一次跑 20 连还在 UX-10 之前）。

## 相对 alpha.4 的主要变化

### 1. ADR-0009 八切片收口（协作语义一年来最大的一次落地）

- **切片②** `run.followup` 下行帧 + 受理 ack + Node 分发（#180/#181）：执行中的追问
  不再"已受理、零痕迹"。
- **切片③** `task_comment → task_message` 实体升级（#185）；讨论流与执行流**读模型隔离**
  （ADR-0010，#194）；执行区指令可起 Run（三段式目标解析 + 双向锚定，#196）；
  同 Task 锚点消息加**库级镜像触发器**（#199，A0 硬化）。
- **切片⑤ resume 续跑全链**（#237）：Runtime 用 persisted load 接上**同一条会话**
  （同 session id、上下文命中、日志线性增长不复制），探针与 wire 两条驱动面都有判据。
- **切片⑥ 运行可观察性**（#208 系列）：任务房间两栏化（讨论｜执行）、Run Console 覆盖层、
  「这句话会在哪里跑」执行目标条、讨论里引用某次运行、任务级权限页。
- **切片⑦ Agent 可被指派**（#239）：指派即指令——Hub 自动产生 `origin='auto_assignment'`
  的指令消息并驱动，指派的人即责任人。
- **切片⑧ 审批档位可配置**（#241）：`approval_required` / `full_access` 固化进 profile
  digest；composer 胶囊让发送前就知情，`full_access` 需显式确认。
- **切片④ 指令权授权**（#198）：授权/撤销/名单的完整管理面。

### 2. 前端 UX 二十批（可用性与诚实性）

- **交互批次①–④**：死链/加载与错误态/缓存失效/错误口径的诚实化（#225）、断线横幅 +
  重连全量补拉 + session 过期跳转（#227）、ConfirmDialog 替代 `window.confirm` + toast
  通道 + `Cmd+Enter`（#229）、执行活动提示与加载骨架（#231）。
- **UX-6…UX-20**：composer 审批档位胶囊、⌘K 全局搜索（任务/项目/Agent 三类实体）、
  最近任务侧栏、运行时长、交付物文本预览 + 「对这个工件继续说」、工具轨迹内联 chip、
  运行卡阶段徽标与落点名、视觉密度审计门、运行完成通知（tab 徽标 + 可选系统通知）、
  闪屏在渲染期被消费的修复、动效底座（交互态/浮层在场/直播产出连续性/内容形态切换连续性）、
  `?` 快捷键速查与搜索空态教一次键位。
- **诚实性修复**：内部 id 不再冒充人名与标签（#162）、破折号前的排版门（#169）、
  深色对比度门不再是盲的（#214）。

## 质量门（发布判据）

- **逐 PR 证据**（全部在 CI 的 pull_request 上真跑）：Q0 静态门（1428 用例 + 7 预期失败）、
  Q2 数据门（63 文件 / 447 集成用例）、Q3 DSH 契约门（39 探针）、Q6 故障门（32 用例）、
  Q7 安全门（18 用例 + secret-scan 自检/实扫 + 依赖许可 gate）。
- **随本 tag 的发布工作流**：Q5 浏览器门 **20× 连续冷启**、Q8 负载短档、Q9 compose 空卷冒烟——
  三者报告**归档为 artifact**，供后续趋势比较。
- Q9 安装门已在 CI 上实跑：alpha.6 tag 的那轮 `compose-smoke` job 全绿（空卷 + 生产同一份
  compose.yml + 宿主真 node CLI），日志归档为 artifact `q9-compose-smoke`。
- Q8 的读法（本版重点）：runner 上的数字**不是判据**（共享 CPU），归档按标签读——
  `PASS-CONSERVATIVE`（欠规保守口径）或 `INCONCLUSIVE`（FAIL 不绿洗）。**本版没有取得权威判**，
  权威判需要在专用 4CPU/8GiB Linux 环境复跑（#298）；同规格 runner 两次量得 116.4ms 与 9.1ms
  （相差 12.8 倍）是该指标不可判的实证。
- 本地预验（发布前）：`pnpm test:e2e` 全 6 project 通过；`bash scripts/q5-loop.sh 3` 与
  `q5-loop.sh 5` 的连跑结果随 tag 记录在发布工作流与验收文档里。
- Q9 本机实录：空卷安装 PASS（冷构建 111.3s，闭环逻辑约 6.9s，15 分钟硬闸内）。

## 已知限制（alpha 明示，不是漏项）

1. **Agent 真执行需要真实模型密钥**。全新安装的环境能一路走到"起 Run"，然后
   **如实失败**（`failed / MODEL_CREDENTIAL_UNAVAILABLE`）——这是设计行为，不是崩溃：
   配好 Node 本机密钥（`whalepod-node secrets`）后才是真实执行。Q9 的机检面到凭证边界
   为止；审批桥/Artifact/Reviewer/验收需要真密钥，由 Phase 2 外部 alpha 覆盖。
2. **敏感不兼容不拒绝启动**（#288）：插件清单的 `dshCompatibility`、Run 的
   `expectedProfileDigest` 目前**只记录不比对**。把本机 DSH 升到与 pack 审过的版本不一致时，
   失败形态可能是运行期怪错误而不是启动前明确拒绝。Alpha 期**锁一版，别自行升级 DSH**。
3. **能力契约未覆盖面**（#289）：单 Run 隔离、指令回执、事件流范围、cancel 竞态在 Q3
   契约门内没有独立判据；「升级失败回滚固定版」只有流程文档、无机检（#290）。
4. **测试代码类型债**（#183）：hub 25 / node 31 个存量类型错误未清；已上棘轮禁新增，
   但没有清零——别把「Q0 全绿」读成「测试代码类型正确」。
5. **多人部署需要 TLS**：会话 Cookie 在非 localhost 强制 `Secure`（#105 裁决维持现状，
   不加危险开关）；LAN 试用走内网 CA/自签 https 或 SSH 隧道，指引见 installation。
6. **不声称性能达标**：Q8 性能门至今**没有可用的权威判据环境**（04 §8 要 4CPU/8GiB Linux 专用机，
   PG 同机；本项目没有）。CI runner 名义规格已达标但 CPU 是共享的——实测 ingest 是判据环境的
   4.7–7.8x，而被轮询节拍压住的传播指标三者几乎一致，属环境形状而非代码回归（#298）。
   已归档的 runner 数字只作趋势证据。**Alpha 期正式口径：不声称任何性能指标达标。**
7. **门禁按风险分级**（G0/G1/G2）：普通 UI 变更不付分布式故障测试成本——这不等于 UI 无缺陷，
   只等于其缺陷不阻塞发布。
8. **单维护者 + AI 自主交付**：协议/migration 类变更走「自查记录留档 + CI 双绿」，
   **不等于第二人评审**；发布前的外部工程师审查仍在争取。
9. **命名冲突未解决**：GitHub 上存在同名不同定位的 `whyihaveyou/whalepod`；
   公开传播前解决（不阻内部/试用）。
10. **附件冻结**（#266）：暂不支持上传附件；不做 Project 级私有 ACL；深色模式（#236）暂缓。
11. **DSH 仍是 Preview 依赖**：不保证不可信插件的强隔离，不保证外部工具副作用可撤销。

**这是 alpha**：安全策略与协议仍在收口，不建议承载真实敏感数据。
