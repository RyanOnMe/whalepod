## 相对 alpha.3 的修复清单（全部有红测与合入实录）

- **#87 / PR #127**（测试基建诚实账）：E2E 装配里 monkey-patch 生产模块的
  做法移除；心跳竞态误标 lost 的观测修复。
- **#88 / PR #128**（alpha.2 已知限制第 4 条之二）：终态 Run 不回收 Runtime
  可占满设备容量——`finalizeRun` 收敛为唯一终点并强制释放（shutdown →
  SIGTERM → SIGKILL 升级链）；Hub 侧以心跳为触发面把「终态仍占容量」的 Run
  收敛掉。E2E 的 Runtime 释放轮询从此是**产品级判据**：超时即回归。
- **#84 / PR #129**（alpha.2 已知限制第 4 条之一）：租约过期 → lost 的路径
  现会折叠该 Run 的 pending Approval（`run_terminal_fold`），审批卡死不再有
  无主窗口；折叠完整性写入 ADR-0007。
- **#94 / PR #130**（alpha.2 已知限制第 2 条）：**`start` 运行期间新增
  Workspace 不再需要重启 Node**——心跳节拍探测 registry 文件指纹，变化即
  重报；Hub 侧全量快照删除收敛（无 Run 引用删行、有引用降级不可用）。
  真 cli 会话 + 独立短进程 add/remove 双向收敛有集成验收。
- **#112 / PR #131**：归因回调缺省不再静默——`onInventoryError` /
  `onHeartbeatError` 忘接时自动回落结构化 stderr warn（`component=node.session`）。
- **#113 / PR #132**（alpha.2 已知限制第 3 条）：反代形态限流不再全队共享——
  nginx 透传 `X-Forwarded-For`，hub 新增 `WHALEPOD_TRUST_PROXY` 开关
  （compose 形态默认开；直连形态默认关，伪造 XFF 无效）。
- **#133 / PR #134**：定名 WhalePod 全量替换（263 文件；curated 插件树走
  确定性重生成，fixture digest 同步回写；ADR/验收/release notes 保留历史名）。

## 已知限制（alpha 明示，不是漏项）

1. **多人部署需要 TLS**：会话 Cookie 在非 localhost 强制 `Secure`（正确的
   安全默认）——`http://192.168.x.x` 形态登录即失效。产品裁决（#105）：
   **维持现状，不加危险开关**；LAN 试用走 https（内网 CA/自签）或 SSH 隧道，
   指引在 `docs/installation.md`。
2. status_request 探针应答不 ack 的重发噪声、SIGKILL 派发在途窗口的
   duplicate→lost 歧义（#90，观察项，无用户可感知损失）。
3. 运行事实的诚实账余量：#123（RECOVER_VERDICT 观测收口）、#124（新生儿
   宽限锚点精确化）为打磨项，挂后续。
4. 插件开发模式（`WHALEPOD_PLUGIN_DEV_MODE`）仅本机可信目录，不做远程加载。
5. Q9 compose 冒烟尚无 per-release CI 挂点（#116 延迟项，本版以本地实跑为证）。

**这是 alpha**：安全策略与协议仍在收口，不建议承载真实敏感数据。
