# 聚焦任务工作区验收

关联 ADR-0018。用户路径：进入任务 → 独立团队留言 → 选择 Agent 执行 → 责任人批准一次
→ 检查私有候选 → 发布给团队 → Task 保持进行中。约定、运行输入与交接、复核仍可达。

## 取证、归因与限制

证据在 `artifacts/evidence/focused-workspace/<随机目录>/facts.json`，只记录白名单事实、Run id
与布局读数，截图作为人工复核材料。独立判定器要求全部六类事实、五档工作区宽度、十类界面的三档宽度、截图及空错误列表，
缺文件、缺环节、重复事实或错误状态一律失败；失败运行不生成 facts.json。

切换丢稿先看 web.workspace 的挂载边界；还焦/锚点失败先看 web.route 与可见视图；
审批或候选错误先看 hub 的受众投影，再看 web 对入口和数量的过滤；执行失败沿
hub.run → node.supervisor → runtime.bridge 归因。

本轮不改服务端协议、状态机、许可或候选权限。真实团队使用感受仍需真人试用，不能用自动化通过替代。
GitHub 访问已恢复，关联 Issue [#387](https://github.com/RyanOnMe/whalepod/issues/387)。此前访问失败的原因是 macOS 登录钥匙串锁定，解锁后已有凭据即可使用。

### 驱动、观测与判定

继续复用本文的生产装配与五类 component，不新增测试专用业务通道。`workspace-hierarchy.spec.tsx` 的三条默认层级检查先红提交，随后实现；`disclosure-panel.spec.tsx` 补充保留字段、外点、嵌套 portal 菜单、Escape、Tab 与 pending 禁用。

`web.micro.conciseDefault` 要求页头高度大于 0 且不超过 80px、默认可见输入区文字不超过 60 字、单一设置入口和无空审批框。1440/390/320 三档均量取设置浮层边界、检查输入框高度不变，并用原生 Tab 进入模式选择、Escape 关闭还焦。菜单定位、减少动态与单输入判据继续保留。终态浏览器另检查直播缓存隐藏、公开最终回复只显示一次。

浮层关闭后字段仍挂载，草稿与准备检查不重置。模式切换保持浮层展开并聚焦新模式控件；pending 时禁用 portal 内字段，焦点移回可用触发器。重新配置、状态变化、权限撤销和完整权限确认继续由原生产守卫判断。Header 的取消仍走确认框；取消确认后焦点返回更多入口，指派锚点仍展开并聚焦真实元数据。

设置定位/键盘问题归因 `web.micro`；任务菜单、确认和锚点归因 `web.route`；草稿/模式归因 `web.execution`；实际启动和权限拒绝沿原 Hub → Node → Runtime 链判断。截图供视觉审评，不能替代机器事实；证据 schema 已增加设置边界和默认层级判据，旧包只作为历史材料。
