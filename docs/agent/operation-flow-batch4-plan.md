## 范围与权利

排序：阻塞执行的待审批优先，随后待接受、待改派、候选检查、真人完成；同一对象只有一项，按事项时间、类型和身份打破并列。返回前12项及hasMore，不返回全团队计数。所有Task终态排除。待审批必须本人Run、当前责任人一致、waiting_approval、pending且未过期；候选按Artifact实际owner，不随Task改派转移；拒绝待改派只给Owner/Admin且无活跃Run；验收完成只给accepted/in_review责任人。聚合不是授权凭证，点击回到既有命令与二次确认。

候选创建沿既有隐私规则不新增全员事件；首页在可见时15秒刷新，终态Run/发布等既有事件即时刷新。未知环境故障不从失败Run猜测，仍使用任务内准备检查。没有真人参与时不声称可用性收益已验证。
