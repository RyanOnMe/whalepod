## 门禁（density-gate.spec.tsx，进 Q1）

- **上限**：全站 cardDepth ≤ 1；hintCount ≤ 4（= 审计后全站最大值，后续候选落地后
  收紧到 3）。高于上限的红，错误文案直接说替代方案（「分层请用留白/边框」「文字请并入
  标签或 placeholder」）。
- **变异自证**：measure() 是纯 DOM 函数，用例喂手工构造的 card-in-card 断言量出 2、
  role=alert 不计入——判据不是恒真摆设。
- 门禁与 copy-typography/theme-contrast 同族：源不审、行为审，页面上真实渲染出来的才算。
