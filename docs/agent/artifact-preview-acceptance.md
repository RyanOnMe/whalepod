# 交付物有脸验收（P1-UX-9 / #250，父账 #243 第 3 条）

## 这条切片改变什么

交付物此前是折叠区里的一行下载链接，要下载到本地才能看。本切片给已发布交付物两件事：
**文本类工件页内可读**（预览钮 → 受控接口取文本 → `<pre>` 内联展示）与**「对这个工件
继续说」**（把来源运行的引用 token 注入讨论输入框并聚焦，#216 同一套窄解析语法，渲染端
零改动）。对照 ChatGPT Work 台的工件面板（#243 取证）；重预览器（图片/PDF/diff 渲染）
明确不做。

## 「不假装能预览」

- 资格判定 `isTextPreviewable(mediaType, byteSize)`（纯函数）：text/* 与 json/xml 族
  （含 +json/+xml），且 ≤512KiB——超出页内不拉，下载兜底。二进制恒不预览。
- 展示截断 `truncatePreview`：64KiB 以内原样；超出截断并标注「内容已截断，完整内容请下载」。
- 三态诚实：加载中（按钮禁用变「加载中…」）/ 失败（提示 + 下载仍在，`artifact-preview-error`）
  / 截断（标注可见）。

## 「对这个工件继续说」的落点取舍

入口注入的是**讨论输入框**（人对人指着工件说，#216 引用 token 在评论区渲染成可点 chip），
不是执行栏指令——ADR-0010 的分工是讨论永不触发运行，驱动 Agent 仍由用户自己去执行栏说。
注入是**追加**不是覆盖（用户可能已打半句），分隔恒空格（窄解析对紧邻 token 的边界有断言），
nonce 保证连点两次落两次账，消费后回调清状态防重复追加。

## 驱动与判定

- **Q1 unit**（`artifact-preview.spec.ts`，4 例）：资格矩阵（text/json/xml yes；图片/PDF/
  zip/octet-stream no；恰好 512KiB yes、+1 no）；截断边界。
- **Q1 页面级**（`artifact-list.spec.tsx` #250 组 5 例）：预览渲染内容；截断标注；失败提示
  且下载仍在；二进制/超大不画预览钮；引用注入后讨论框带 token 且聚焦（toHaveValue 精确匹配
  + toHaveFocus）。
- **Q0**：`pnpm check` 全绿（107 文件 1352 过 / 7 预期失败为既有深色 it.fails 债）。

## 设计取舍记录

- 预览与下载走**同一个受控接口**（`GET /artifacts/:id/content`，Session Cookie）——不新增
  API 面，可见性口径（owner 或 published 后的成员）复用既有路由守卫。
- candidate（owner-only 待发布）不加入口：它是瞬态，发布后自然获得。
- 注入状态放页面（`insertToken`），composer 只消费——组件不反向知道交付物区的存在。

## 边界与债

- diff 形态（两次发布对比）未做：需要「上一版」数据面，属新切片；当前以内容预览 + sha256
  摘要覆盖「看它产出什么」。
- 预览无语法高亮（纯 `<pre>`）；大文件的浏览器内存由 512KiB 拉取上限兜住。
- Q5 e2e 挂 #243 总账既有债。
