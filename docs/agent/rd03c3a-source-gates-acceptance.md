## 用户路径与当前状态

责任人在既有 Task 的获批派工上显式选用受管来源档。当前版本认识这个选择，但没有可验证的完整来源执行路径，因此返回固定的 409：不创建 Run、不发设备命令，也不消耗获批意图。责任人仍可独立选择普通派工；同一个幂等键不能把普通 Run 回执用作受管档回执。

数据库的 `run.managed_draft_source_digest` 只能在 Run 创建时写入，必须和机器来源、受限审批档、无历史或普通输入等条件同时成立，旧 Run 不回填。普通上传、正文、预览、批注、交接、追问、续跑和通用投影不处理未正式发布的受管内容；普通派工不会下发受管执行，普通事件收口不以设备给出的受众覆盖标记。这是保护旧入口的代码，当前没有从生产路径生成受管候选，尚无受管候选穿透各入口的动态证据。

## 复跑与判定

```bash
scripts/run-rd03c3a-component-checks.sh
```

复跑需 Node 24 和可用的本机 PostgreSQL 容器环境。2026-11-09 在 macOS 宿主实际跑通：25 项单元、98 项真实 PostgreSQL 集成、21 项 DSH/运行器组件。运行器的内核隔离只在 macOS 验证；Linux、未知宿主及正式模型提供方未测，不得开启。全量 `pnpm check` 236 文件/2,555 项通过；`pnpm test:security` 18 项及敏感扫描、依赖许可检查通过。

- 真实 PostgreSQL、生产 HTTP：获批派工要求受管档时连续两次得到 409，`run` 和 `dispatch_outbox` 无新增，意图仍为 `approved`；显式普通派工成功，再请求受管档仍不能重用该 Run。尝试修改普通 Run 的持久标记必须被数据库拒绝，不得留下修改。测试先在旧入口的 400、随后在不存在标记的 42703 跑红。
- 首个来源登记：仅当前责任人创建后未被编辑、并由同一人确认的最新任务约定可登记；保存来源字节摘要、接收人、再交付用途、模型出口身份和期限。来源换版、受管模型绑定变化、撤销、停用或改派均拒绝旧登记。改派 A → B → A 的旧登记复活曾实际跑红，现由改派事务同步撤销。
- 固定清单要求调用方先提供独立核验的受管现场，缺少该事实时拒绝，且检查当前 Mandate 并冻结约定、模型和到期；控制面契约拒绝自由指令、工作区路径、凭据槽和会话复用。该清单组件不写 Run 或出站队列。
- 普通派工、Artifact、团队审阅、实时消息保留已有对照。
- 阅稿资格组件：输入是服务端应在授权事务内取得的事实。正常完成、所有者、固定候选字节、写件与上传回执、当前 Mandate 和每一项来源权限均吻合时才给出最晚期限；16 项组件断言覆盖历史/失败 Run、普通上传、错误摘要、错用户/项目、换代与到期。组件通过不授予下载权。
- DSH 组件：固定 boot 的真实 Agent 的首轮及工具后的次轮都走同一个模型端口，端口拒绝越界 provider/model/session、辅助请求和取消；异常不携带来源字节，显式再试产生新的 attempt。macOS 上打包后的来源进程通过文件和网络隔离负控；真实本地 HTTP 接收端的出站检查证明授权绑定到发送字节，先撤权时零请求，重复与跳转均不重发。工作进程正常退出后，采集器复开固定空根内新写的文件并校验写件回执和字节；替换、软硬链接、失败退出、大小或摘要异常、重复采集均拒绝。这仍未证明线上 Hub 到设备的出站复核。

## 归因与取证

派工异常先看生产 HTTP 判据、`dispatch_intent` 状态、`run` 与 `dispatch_outbox` 的计数。历史候选误分类先核对源 Run 的持久标记与迁移状态。资格证据只记录稳定拒绝原因；禁止在通用日志与证据包记正文、模型请求、候选标题、令牌、凭据或本机路径。通过运行结果和数据库断言区分组件、兼容回归与未运行的端到端场景，不记录虚构的 grant 或出站回执。

## 未达到的退出条件

已有来源登记、冻结清单与运行器组件；尚未连接用于真实受管设备的派工与能力验证、Hub 在线出站裁决、正常 Run/独立新写/上传的三方闭合，也没有 A 核稿、B 接受及读取、撤销与首字节竞态的生产链。完整验收须补真实装配、独立判定、脱敏证据包及关键守卫变异；在这些证据与独立评审齐备前保持关闭。没有开发 c3b。


后续接线须使用独立受管命令及设备凭据；现有普通 `run.start` 会装配 Workspace、通用凭据及自由指令，不能复用。Router 的模型开始回执也只说明 Node 已把帧写到连接，不能作为 Hub 已在线放行。受管设备需要可信部署记录、独立服务身份或隔离部署，以及不与普通执行共享可写目录；配对设备自报的能力不足为证。
