# ⌘K 三类实体搜索验收（P1-UX-15 / #263，父账 #243 后续·P1-UX 三期刀三）

## 这条切片改变什么

⌘K 此前只搜任务标题（#254）。本刀一条输入搜三类：**任务**（服务端）+ **项目/Agent**
（本地过滤已有缓存），↑↓ 在扁平结果序列里跨段连续走，Enter 落点带锚点高亮。
对照 ChatGPT 的 ⌘K：一处输入、多类实体、纯键盘可走。

## 数据面（零新端点）

- **任务**：`GET /tasks/search?q=`（不变，#254 的 ILIKE 与 ≤8 条）；
- **项目 / Agent**：**客户端子串过滤** `queryKeys.projects` / `queryKeys.agents` 的缓存列表
  （浮层打开时才取数）。团队规模下这两组是个位数量级——为它们新建搜索端点等于再养两份
  ILIKE 与索引，是把简单问题复杂化。
- 与各页面**共用同一 queryKey**：从项目页/Agents 页呼出搜索时不产生新请求（缓存复用）。

## UI 契约

- 三段：任务 / 项目 / Agent；段头是 `<p>` 小字（不是标题元素、不是可选项——搜索浮层
  不该长出一套文档大纲）。
- 扁平序列：`hits = 三段顺次拼接`，↑↓ 与 Enter 都作用在扁平索引上；段内无命中则该段
  **整段不渲染**（连段头都不画）。
- 落点：任务 → `/tasks/<id>`；项目 → `/#project-<id>`；Agent → `/agents#agent-<id>`。
  后两者由 `shared/useHashFocus.ts` 接住：滚进视口 + 2s 描边高亮（hash 可复制、可分享、
  刷新不丢，且**不用**给这两个页面立「选中项」的 URL 契约）。
  两个陷阱都已处理：数据未就绪时元素不存在（`ready` 进依赖，列表落地后再找一次）、
  jsdom 没有 `scrollIntoView`（同 window.focus：没有就只标亮不滚动）。
- **可访问名改了**：dialog `搜索任务` → `全局搜索`，输入框 `搜索任务` → `搜索关键词`。
  理由：浮层已经不止搜任务，留旧名字就是撒谎；#254 的既有 spec 5 处引用同步更新（判据未弱化）。

## 诚实面（不猜、不装）

- 空关键词：不发 `/tasks/search`（本地列表取数不算「搜索」）；
- 三段都空：`没有匹配的任务、项目或 Agent`；若此时本地列表是**读取失败**（不是空），
  后缀如实标出「（项目/Agent 列表读取失败）」——不替失败的那段说「没有」；
- 项目结果显示名与「创建于/已归档」，Agent 显示名与描述（**不显示 id**，同 #211 口径）。

## 驱动与判定

- **Q1 web**：新增 `apps/web/tests/global-search-entities.spec.tsx` 4 例——
  三段齐出 + ↑↓ 跨段 + 项目落点高亮；Agent 落点高亮（大写关键词命中小写名，验大小写不敏感）；
  空关键词不发请求 + 段内无命中不渲染段头 + 三段都空如实说；本地列表失败如实标缺口。
  既有 `global-search.spec.tsx` 5 例（呼出/侧栏钮/Esc 还焦/无结果/键盘路径）改名后全绿。
- **变异自测**（门要能被证伪）——三刀全红：
  | 变异 | 结果 |
  |---|---|
  | 空段也进列表（去掉 `hits.length > 0` 过滤） | 红（只有项目命中时 Agent 段头冒出来） |
  | 去掉客户端名字过滤（不过滤直接取前 N） | 红 ×2 |
  | 去掉项目页的 `useHashFocus` | 红（锚点高亮断言） |
- **Q0**：`pnpm check` 全绿（113 文件 1382 过 / 7 预期失败为既有深色 `it.fails` 债）。

## 踩坑记录

1. **变异自测要先确认变异真的生效**：第一次掐「空段不进列表」时 perl 正则没匹配到那一行
   （`.filter(...)` 与 `]` 同行），文件根本没改，于是「绿」——绿得毫无意义。重写正则后
   才是真变异（红）。**变异不生效的绿，比不跑变异更危险**。
2. **测试数据要按关键词设计**：Agent 名字是 `login-helper`，第一版用例却用中文「登录」
   去命中它，Agent 段根本没出现——断言先红在测试数据上，不是实现上。
3. **改可访问名会连带既有 spec**：dialog/输入框改名要同步改 5 处既有断言（`name: '全局搜索'`、
   `getByLabelText('搜索关键词')`）；改名本身是诚实性修复（浮层已不止搜任务）。
4. jsdom 无 `scrollIntoView`：`useHashFocus` 里必须判 `typeof === 'function'`，
   否则单测里直接抛（与 `window.focus()` 同类）。

## 边界与债

- 不做模糊匹配（子串、大小写不敏感——可预测比"聪明"重要）；不做动作类命令
  （新建项目/新建任务）；不搜消息正文/交付物内容（新数据面）。
- 项目/Agent 的落点是「列表页 + 锚点高亮」，不是专属详情路由——给这两个页面立选中项
  URL 契约是另一件事，本刀不做。
- 高亮 2s 后自动撤（`HIGHLIGHT_MS`）；窄屏与宽屏同一套（浮层宽度 `min(520px, 90vw)`）。
